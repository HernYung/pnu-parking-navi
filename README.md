# JARI 자리

JARI(자리)는 부산대학교 부산캠퍼스 주차 안내 3D 내비게이션 HTML 앱 프로토타입입니다(창의적 문제해결력 조별과제).

- 열기: https://hernyung.github.io/pnu-parking-navi/
- 휴대폰에서 열면 위치 권한을 허용했을 때 실제 현재 위치(GPS)와 실제 시각으로 안내합니다.
- 빈자리 수, 하역·승하차 구역, 넉넉한터 지하주차장 위치, 정문·북문을 뺀 출입구 이름은 시연용 예시·추정 값입니다.

## 데이터 출처

- 지도(건물·도로·주차장·장소): © OpenStreetMap 기여자, [ODbL](https://opendatacommons.org/licenses/odbl/)
- 지형 높이: SRTM 30 m (OpenTopoData)
- 3D: [three.js](https://threejs.org/) r128 (CDN)
